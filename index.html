Project one — RAG / LangGraph

Nexora Insider

What if a RAG system didn’t trust its own first retrieval?

I built Nexora from basic RAG experiments into a production-oriented knowledge assistant designed around one problem: making retrieval systems more reliable, efficient, and honest.

Instead of blindly generating from retrieved context, Nexora can:

  • RouteDecide whether a query needs retrieval, calculation, or direct generation.
  • RetrieveSearch the knowledge base semantically.
  • GradeVerify whether the retrieved context actually answers the question.
  • RewriteReformulate failed queries and retrieve again.
  • GuardBlock prompt injection and unsafe requests.
  • CacheRecognize semantically equivalent questions and reuse results.
  • OptimizeDynamically reduce unnecessary model calls through model tiering.

The numbers

42% → 84%Routing accuracy
6–8s → <0.5sRepeated-query latency
~95%Semantic-cache speedup
5–7 → 3–4Model calls per workflow

What makes it different

Built progressively from first-principles RAG experiments rather than starting with a framework-heavy template. The repository preserves that evolution — from isolated LangChain experiments to the final LangGraph orchestration — alongside evaluation code and a 19-question routing benchmark.

Stack

LangGraph · LangChain · Gemini · Chroma · SQLite · Streamlit

Project two — Python / MCP

RepoMind

AI that understands a codebase, not just its code.

What problem does it solve?

Understanding an unfamiliar repository means tracing structure, dependencies, functions, and architecture across files.

RepoMind turns a GitHub repository into a queryable intelligence layer for developer questions.

How is it different?

Most code-RAG systems retrieve similar code. RepoMind combines semantic retrieval with structural understanding.

  • AST AnalysisCode structure.
  • Dependency GraphsRelationships.
  • Function EmbeddingsPrecise retrieval.
  • Specialized AgentsTask-specific reasoning.
  • MCPRepository-aware tools.

What can it do?

Ask:

Where should I start contributing?

What breaks if I change this module?

How does this component connect to the rest of the system?

Answers are grounded in the actual repository.

Built with

Python · MCP · AST · ChromaDB · Sentence Transformers · NetworkX · Gemini

Don’t just retrieve the code. Understand the system around it.
